Japan in Seasons is a free map of seasonal forecasts for Japan, with a public API and an MCP server for AI assistants. Koo Haoming runs it as an individual in Singapore. By using it you agree to these terms.

Forecasts can be wrong

Forecasts and spot reports come from the Japan Meteorological Corporation, the Japan Meteorological Agency, Open-Meteo and official tourism and organiser websites. They can be wrong, late or out of date, and festival dates can change. Check the official source before you book or travel.

Fair use of the API and MCP server

The API and MCP server are free to use, including for commercial projects. Each visitor is limited to 60 requests a minute so the service stays up for everyone. Don't try to get around the limit or overload the service.
